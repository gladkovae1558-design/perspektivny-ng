# Перспективный Новый год — страница события

Адрес: https://gladkovae1558-design.github.io/perspektivny-ng/

## Как поправить текст прямо в браузере
1. Откройте файл `index.html` в этом репозитории и нажмите значок карандаша (Edit).
2. Найдите нужное место через Ctrl+F:
   - контакты — ищите `ОРГАНИЗАТОР` или `tel:`;
   - программа — ищите `ПРОГРАММА`;
   - дресс-код — ищите `ДРЕСС-КОД`.
3. Нажмите **Commit changes**. Через 1–2 минуты сайт обновится сам.

## Как добавить ролик
Загрузите файл в папку `assets` с именем `teaser.mp4` (Add file → Upload files, до 100 МБ),
затем в `index.html` уберите две строки-комментария вокруг блока «РОЛИК».

Страница открыта по ссылке и закрыта от поисковиков (`noindex`).
